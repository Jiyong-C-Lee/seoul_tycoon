# UI/UX 디자인 가이드

## 1. 디자인 컨셉

- **핵심 키워드**: 미니멀리즘, 아이소메트릭(Isometric), 그리드(Grid), 직관성
- **레퍼런스 스타일**: 깔끔한 벡터 그래픽 느낌의 아이소메트릭 타일 디자인 (참고 이미지 2번 스타일)
- **화면 구성 철학**:
  - **지도 우선 (Map-First)**: UI가 화면을 가리지 않고, 지도가 시원하게 보이도록 배치
  - **온디맨드 정보 (On-Demand Info)**: 평소에는 숨겨져 있다가, 유저가 원할 때(클릭) 패널을 열어서 정보 확인
  - **그리드 일관성**: 모든 오브젝트는 격자 규칙을 따름

---

## 2. 메인 화면 레이아웃

### 2.1 전체 구조 (HUD)

화면은 **상단 정보바**, **전체 지도**, **우측 플로팅 메뉴**로 간결하게 구성됩니다.

```
┌─────────────────────────────────────────────────────┐
│  [상단 바] 타이틀 | 2004.03 | ▶ (2x) | 현금 5.0억   │
├───────────────────────────────────────┬─────────────┤
│                                       │             │
│                                       │   [우측]    │
│            [중앙] 전면 지도            │   메뉴 바   │
│         (선릉역 주변 지형 예시)        │             │
│                                       │    (🔵)     │
│      - 1x1 그리드 타일 기반             │    (🔵)     │
│      - 건물, 도로, 숲, 산  배치        │    (🔵)     │
│                                       │    (🔵)     │
│                                       │             │
│                                       │             │
└───────────────────────────────────────┴─────────────┘
```

### 2.2 영역별 상세 정의

#### A. 상단 바 (Top Bar)
- **위치**: 화면 최상단 가로바
- **높이**: 50~60px
- **스타일**: 반투명 배경 or 깔끔한 플랫 디자인
- **구성 요소**:
  - 좌측: 게임 로고 (심플한 텍스트)
  - 중앙: **날짜** (연/월), **시간 제어** (재생/일시정지/배속), **속도 표시**
  - 우측: **핵심 자원 요약** (현금 보유량) - *상세 자산은 패널로 숨김*

#### B. 우측 메뉴 바 (Right Floating Menu)
- **위치**: 우측 중앙~하단에 세로로 배치
- **스타일**: **동그라미 아이콘 (Circular Floating Buttons)**, 그림자 효과로 떠 있는 느낌
- **구성 (위에서 아래로)**:
  1. 📊 **자산 상세**: 클릭 시 좌측 패널 슬라이드 오픈 (자산, 부채, 등급 등)
  2. 📰 **뉴스/정보**: 클릭 시 뉴스 피드 팝업
  3. 🗺️ **지도 필터**: 시세 보기 / 등급 보기 / 소유주 보기 모드 전환
  4. ⚙️ **설정**: 게임 옵션 메뉴

#### C. 메인 지도 (Main Map) - 선릉 예시
- **시점**: 아이소메트릭 뷰 (Isometric View)
- **구성**:
  - 화면 전체를 꽉 채우는 그리드 라인 (아주 연하게 표시)
  - 유저는 드래그로 이동, 휠로 확대/축소 가능 (초기엔 고정)
  - **선릉역 사거리**를 중심으로 한 도로망과 **선정릉**의 녹지 표현

## 3. 인터랙션 및 패널 (Pop-up Systems)

기본적으로 좌측/하단 패널은 닫혀있으며, 유저 인터랙션 시에만 나타납니다.

### 3.1 타이틀 및 시작 화면 (Title Screen)
- **레퍼런스**: *Mini Motorways Intro* 스타일
- **구성**:
  - 심플한 서울 전체 지도 (배경)
  - **지역 선택 인터페이스**: 지도상의 특정 구역(예: 강남구, 역삼동)이 하이라이트됨
  - 플레이어가 지역을 클릭하면 해당 맵으로 줌인되며 게임 시작

### 3.2 건물 상세 팝업 (Building Detail Popup)
지도상의 건물을 클릭하면 **화면 좌측**에 상세 정보 팝업이 나타납니다.

- **위치**: 좌측 중앙 or 상단 (우측 메뉴와 겹치지 않게)
- **구성**:
  - **헤더**: 건물명, 용도(주거/상업/오피스), 등급(별 개수)
  - **정보**:
    - 매매가 / 월 임대료
    - 수익률 / 공실 리스크
  - **시각화**: 최근 시세 변동 **선 그래프 (Line Chart)**
  - **액션 버튼**: [매수/매도], [리모델링] (조건 충족 시)
- **특이사항**: 건물 사진이나 이미지는 사용하지 않고, 텍스트와 그래프 위주의 인포그래픽 스타일 적용

### 3.3 뉴스 및 이벤트 (News & Events)

#### A. 주요 이벤트 (Major Event) - *MVP 구현*
- **작동**: 게임 시간이 **일시정지(Pause)** 됨
- **UI**: 화면 중앙에 팝업 또는 상단에서 내려오는 토스트 메시지 형태
- **내용**: 정책 변경안, 개발 호재 발표 등
- **상호작용**: 반드시 **선택지**를 골라야 창이 닫히고 시간이 다시 흐름

#### B. 티커 알림 (Ticker Notification) - *Post-MVP (추후 구현)*
- **스타일**: Mac OS 알림 배너처럼 우측 상단에 쌓이는 형태
- **내용**: 자잘한 시세 변동, 날씨, 루머 등 (게임 진행 방해 X)
- **MVP**: *현재 단계에서는 구현하지 않음*

### 3.4 자산 현황 (Asset Panel)
우측 `📊` 아이콘 클릭 시 **좌측 패널**이 열립니다 (`Toggle` 방식).
- **내용**:
  - 상세 현금, 총 자산, 순자산, 대출 현황
  - 월간 수입/지출 내역

### 3.5 게임 종료 화면 (Game Over / Result)
30년 종료 또는 파산 시 출력되는 최종 화면입니다.

- **구성**: 좌우 분할 레이아웃
  - **좌측 (성적표)**: 최종 등급(S~F)이 크게 표시되고, 획득한 칭호와 평가 텍스트 출력
  - **우측 (인포그래픽)**: 
    - 30년간의 자산 변화 추이 그래프
    - 주요 달성 기록 (최고 수익률, 보유 건물 수 등)

## 4. 그리드 시스템 및 오브젝트 가이드 (Graphic Guidelines)

모든 게임 내 오브젝트는 **Isometric 1x1 Grid** 시스템을 철저히 따릅니다. 예외적인 자유 배치(Free-form placement)는 허용하지 않습니다.

### 4.1 그리드 규칙
- **기본 단위**: 모든 요소는 정사각형 타일(1x1 Grid) 단위로 제작 및 배치됩니다.
- **확장형 오브젝트**: 2x2, 3x3 크기의 대형 오브젝트(랜드마크, 공원 입구 등)도 그리드 칸 수에 맞춰 제작합니다.
- **배치 원칙**: 도로, 건물, 자연물 모두 타일 경계선 내에 완벽하게 포함되어야 합니다.

### 4.2 타일 및 오브젝트 정의

**1. 도로 (Road)**
- 아스팔트 색상의 1칸 타일
- 선릉역 사거리(십자 교차로), 테헤란로(직선 도로) 표현

**2. 건물 (Building) - 모듈형 규격화**
건물 이미지는 **[용도] x [등급] x [상태]** 조합에 따라 규격화된 이미지를 사용합니다.

- **용도별 테마 컬러 (Base Color)**:
  - **오피스 (Office)**: 🟦 블루/청록 (유리 통창, 현대적 느낌)
  - **상가 (Commercial)**: 🟧 오렌지/옐로우 (활기찬 간판, 낮은 층고)
  - **주거 (Residential)**: ⬜ 베이지/화이트 (따뜻한 벽돌, 아파트)
  - **공공 (Public)**: ⬛ 회색/검정 (엄격한 석조 건물)

- **등급별 형태 (Shape Variation)**:
  - **C급 (Low)**: 1~2층의 낮은 건물, 단순한 형태
  - **B급 (Mid)**: 3~5층의 중간 크기 건물
  - **A급 (High)**: 10층 이상의 고층 빌딩
  - **S급 (Landmark)**: 화려하고 독특한 디자인 (2x2 타일 가능)

- **상태 표현 (Condition Overlay)**:
  - **노후화**: 건물 텍스처에 크랙이나 얼룩 추가 (Overlay)
  - **리모델링 중**: 공사 가림막/비계(Scaffolding) 이미지로 대체
  - **매물 (For Sale)**: 건물 위에 `$` 아이콘 플로팅

**3. 자연 (Nature) - 그리드 귀속**
자연물도 자유로운 곡선이 아닌, **그리드에 맞춰진 블록 형태**로 표현합니다.

- **숲/공원 (Park Block)**: 1칸을 꽉 채우는 나무 군집 타일. (여러 개를 붙여서 대형 공원 표현)
- **잔디 (Grass)**: 나무 없이 바닥만 녹색인 평지 타일.
- **선정릉 구현**: 이러한 녹색 타일들의 집합으로 도심 속 거대 녹지를 표현 (테두리는 그리드 따라 계단식 처리될 수 있음)

**4. 상태 표시 (Interaction Feedback)**
- **소유한 건물**: 해당 건물 **바닥 타일**이 **초록색(Mint)**으로 변경
- **마우스 오버 (Hover)**:
  - 해당 건물 **바닥 타일**이 **파란색(Blue)**으로 변경 (반투명)
  - **정보 툴팁(Tooltip)** 즉시 표시: 건물명, 시세, 미니 차트
**5. 특수 오브젝트 (Overlay Objects)**
지하철역이나 버스 정류장은 바닥 타일(도로, 건물) 위에 **겹쳐서(Overlay)** 배치됩니다.

- **지하철역 (Subway Station)**: 
  - **형태**: 도로 타일 위에 떠 있는 **'M' 로고 폴사인(Pole Sign)** 또는 지하도 입구 구조물
  - **특징**: 바닥 타일의 원래 속성(도로 등)을 유지하면서 추가적인 기능(역세권)을 부여함
  - **배치**: 주로 교차로(사거리) 도로 타일 위에 배치됨

## 5. UI 컬러 팔레트 (제안)

전체적으로 차분하고 깔끔한 톤을 유지합니다.

- **배경(Ground)**: `#F0F2F5` (눈이 편안한 연회색)
- **도로(Road)**: `#DFE4EA` (배경보다 약간 진한 회색) or 흰색 도로
- **UI 포인트**:
  - 긍정/소유: `#2ED573` (선명한 민트 그린)
  - 부정/비용: `#FF4757` (워닝 레드)
  - 강조/선택: `#3742FA` (비비드 블루)
- **패널 배경**: `#FFFFFF` + 은은한 그림자 (Shadow)
