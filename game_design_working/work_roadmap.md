## 🔧 개발 우선순위 (기획 완료 후)

### Phase 1: MVP (1~2회차 시스템) ⭐ 최우선
**목표**: 플레이 가능한 최소 버전, 코어 루프 검증

#### 필수 구현
- **기본 게임 루프**: 시간 진행, 매수/매도, 10년 완주
- **지도 시스템**: 1개 동 지역, 5~10개 건물
- **경제 시스템**: 시세 변동, 임대료 수입, 현금/자산 계산
- **UI/UX**: 지도 뷰, 건물 리스트, 기본 차트, 자산 패널
- **종료 조건**: 30년 경과, 파산 감지, 등급 표시

#### 제외 항목
- ❌ 리모델링, 대출, 정책 개입, 이벤트, 지역 확장

**예상 기간**: 4~6주

---

### Phase 2: 건물 관리 시스템 (3회차)
**추가 구현**: 리모델링, 임대료 조정, 건물 등급, 세입자 이벤트  
**예상 기간**: 2~3주

### Phase 3: 금융 시스템 (4~5회차)
**추가 구현**: 대출(LTV), 이자, 부채 관리 UI, 파산 경고  
**예상 기간**: 2~3주

### Phase 4: 고급 시스템 (6회차+)
**추가 구현**: 정책 개입, 지역 확장, 랜드마크, 이벤트, 업적  
**예상 기간**: 4~5주

### Phase 5: 밸런싱 및 폴리싱
**작업 내용**: 밸런싱, UI/UX 개선, 버그 수정, 플레이 테스트  
**예상 기간**: 2~3주

## 💡 개발 전략 원칙

1. **Play Early, Play Often**: MVP를 빠르게 만들어 플레이 테스트
2. **점진적 추가**: 한 번에 1개 시스템씩 추가하고 검증
3. **기획 완료 후 개발**: 해당 Phase 기획 문서 완료 후 개발 시작
4. **우선순위 준수**: Phase 순서대로 개발, 건너뛰지 않기
