# 서울 부동산 타이쿤 - 프로젝트 개요

## 게임 컨셉
서울에서 부동산 투자자가 되어 자산을 불리는 실시간 경제 시뮬레이션 게임

## 핵심 재미
1. **타이밍 기반 투자**: 저점 매수, 고점 매도의 타이밍 전략
2. **확률적 시장 개입**: 정책 선택, 이벤트 대응으로 시장에 영향력 행사
3. **포트폴리오 관리**: 분산/집중 투자, 레버리지 활용
4. **자산 성장**: 5억 → 1,000억까지 성장하는 경험

## 핵심 특징
- **장르**: 실시간 경제 시뮬레이션 (일시정지 가능)
- **플랫폼**: Python + Pygame
- **플레이 타임**: 18분 (게임 내 30년)
- **시작 자본**: 5억 원
- **속도 조절**: 1배속 / 2배속 / 4배속

## 게임 목표
- 30년(360개월) 동안 순자산 최대화
- 파산 방지 (순자산 -5억 이하)

## 주요 메커니즘
1. **부동산 매매**: 건물 매수/매도, 타이밍 전략
2. **시세 변동**: 실시간 가격 변동, 정책/개발/경제 이벤트 영향
3. **임대 수익**: 보유 건물에서 월 임대료 수익
4. **이벤트 개입**: 정책 방향 선택, 이벤트 대응, 시장 개입
5. **건물 관리**: 리모델링, 용도 변경, 임대료 책정, 세입자 선택
6. **금융 시스템**: LTV 기반 대출, 월별 이자 상환
7. **맵 확장**: 자산 증가에 따라 강남구 → 서울 전역

## 승리 조건
30년 완주 + 최종 순자산 최대화

## 패배 조건
- 파산: 순자산 -5억 이하
- 신용불량: 12개월 연속 이자 미납

## 플레이어 성장 전략 (PLC 확보)

### 진입 장벽 최소화
- **캐주얼한 그래픽**: Mini Metro 스타일의 간결하고 직관적인 디자인
- **낮은 학습 곡선**: 최소한의 튜토리얼로 즉시 플레이 가능
- **명확한 피드백**: 시각적으로 명확한 자산 증감 표시

### 점진적 깊이감 제공
- **해금 콘텐츠**: 플레이 진행에 따라 점진적으로 시스템 해금
  - 1회차: 기본 매수/매도만
  - 2~3회차: 리모델링, 대출 시스템 해금
  - 4~5회차: 정책 개입, 지역 확장 해금
- **선택지 증가**: 숙련도에 따라 전략적 선택지 확대
- **자유도 상승**: 초기 가이드 → 후기 자유도 극대화

### 반복 플레이 유도
- **짧은 플레이타임**: 30~60분으로 부담 없는 1회 플레이
- **다양한 난이도**: 시작 지역/건물 선택으로 난이도 조절
- **등급 시스템**: F~S 등급으로 재도전 동기 부여
- **업적 시스템**: 랜드마크 보유, 특수 조건 달성
