# 서울 부동산 타이쿤 - 프로젝트 개요

## 게임 컨셉
서울에서 부동산 투자자가 되어 30년간 건물을 사고팔며 자산을 증식시키는 실시간 경제 시뮬레이션 게임

## 핵심 재미
1. **타이밍 기반 투자**: 저점 매수, 고점 매도의 타이밍 전략
2. **확률적 시장 개입**: 정책 선택, 이벤트 대응으로 시장에 영향력 행사
3. **포트폴리오 관리**: 분산/집중 투자, 레버리지 활용
4. **자산 성장**: 5억 → 1,000억까지 성장하는 경험

## 핵심 특징
- **장르**: 실시간 경제 시뮬레이션 (일시정지 가능)
- **플랫폼**: Python + Pygame
- **플레이 타임**: 18분 (게임 내 30년)
- **시작 자본**: 5억 원
- **속도 조절**: 1배속 / 2배속 / 4배속

## 게임 목표
- 30년(360개월) 동안 순자산 최대화
- 최종 순자산에 따른 등급 획득 (F ~ S)
- 파산 방지 (순자산 -5억 이하)

## 주요 메커니즘
1. **부동산 매매**: 건물 매수/매도, 타이밍 전략
2. **시세 변동**: 실시간 가격 변동, 정책/개발/경제 이벤트 영향
3. **임대 수익**: 보유 건물에서 월 임대료 수익
4. **확률적 개입**: 정책 방향 선택, 이벤트 대응, 시장 개입
5. **건물 관리**: 리모델링, 용도 변경, 임대료 책정, 세입자 선택
6. **금융 시스템**: LTV 기반 대출, 월별 이자 상환
7. **맵 확장**: 자산 증가에 따라 강남구 → 서울 전역

## 승리 조건
30년 완주 + 최종 순자산 기준 등급
- S등급: 1,000억 이상
- A등급: 500~999억
- B등급: 100~499억
- C등급: 50~99억
- D등급: 10~49억
- F등급: 10억 미만

## 패배 조건
- 파산: 순자산 -5억 이하
- 신용불량: 12개월 연속 이자 미납
