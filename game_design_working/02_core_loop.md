   - 초기 자본: 5억 원
   - 지역 선택: 서울 랜덤 동 (난이도 요소)
   - 초기 건물 선택 (난이도 요소)

**[지도 탐색]** → 섹션 3.2에서 상세 작성
2. 지도 확인
   - 매수/매도 가능 건물 표시
   - 관공서, 랜드마크 표시
   - 산/강 자연 환경 표시

**[핵심 반복 루프]** ← 3~5번 반복
3. 정보 확인 및 행동 → 섹션 4에서 상세 작성
   - **정보 확인**: 시세 차트, 뉴스, 보유 현금/순자산, 월 임대료, 대출 이자
   - **행동 선택**: 매수/매도/리모델링/임대료 조정/대출/상환

4. 시간 진행 (1개월 단위) → 섹션 2.1에서 상세 작성
   - 임대료 수입 자동 입금
   - 대출 이자 자동 차감
   - 시세 변동
   - 이윤/손실 발생

5. 이벤트 발생 (랜덤) → 섹션 5에서 상세 작성
   - **5-1. 건물 이벤트**: 건물 등급 변동, 세입자 이벤트
   - **5-2. 정책/시장 이벤트 (뉴스)**: 시세 폭등, 정부 규제 → 선택지
   - **5-3. 환경 이벤트**: 자연재해, 관공서 이전
   - **5-4. 지역 확장**: 특정 금액 달성 시 지역 확장 (대가 지불 or 자동 해금)

**[게임 종료]**
6. 종료 조건
   - 30년 경과 → 최종 결산 → 등급 부여
   - 또는 파산 (순자산 -5억) → 게임 오버

## 1. 코어 루프 개요

**서울 부동산 타이쿤**의 코어 루프는 크게 3단계로 구성됩니다:

### 1.1 게임 구조

**[1단계] 게임 시작 (1회)**
- 2004년 1월, 초기 자본 5억 원
- 지역/건물 선택 (난이도 결정)
- 초기 상태 확인

↓

**[2단계] 핵심 반복 루프 (30년간 반복)**

A. 정보 수집 및 분석
   - 시세 차트, 뉴스 확인
   - 보유 자산 상태 파악

B. 전략적 행동
   - 매수/매도 결정
   - 건물 관리 (리모델링, 임대료)
   - 금융 관리 (대출/상환)

C. 시간 진행 (1개월 단위)
   - 자동: 임대료 수입, 이자 차감, 시세 변동
   - 결과: 자산 증감

D. 이벤트 대응
   - 건물/정책/환경 이벤트
   - 선택지 제시 → 플레이어 선택

↻ (A로 돌아가서 반복)

↓

**[3단계] 게임 종료 (1회)**
- 30년 경과 → 최종 결산 → 등급 부여
- 또는 파산 (-5억) → 게임 오버

### 1.2 핵심 반복 사이클

플레이어는 2단계에서 다음 사이클을 **30년(360개월) 동안 반복**합니다:

```
정보 확인 → 판단 → 행동 → 시간 진행 → 결과 확인 → 이벤트 대응
    ↑                                                      ↓
    └──────────────────────────────────────────────────────┘
```

**사이클 주기**:
- **빠름**: 1~3분에 1회 (게임 내 3~9개월)
- **보통**: 5~10분에 1회 (게임 내 1~2년)
- **느림**: 관망 모드, 이벤트 발생 시에만 개입

### 1.3 자동 vs 수동

| 구분 | 자동 진행 (70%) | 플레이어 개입 (30%) |
|------|----------------|---------------------|
| **시간** | 1개월씩 자동 진행 | 일시정지 & 판단 |
| **수입/지출** | 임대료, 이자 자동 처리 | 대출/상환 결정 |
| **시세** | 매월 자동 변동 | 매수/매도 타이밍 포착 |
| **이벤트** | 랜덤 발생 | 선택지 대응 |

### 1.4 핵심 설계 원칙

1. **빠른 피드백**: 행동 → 결과까지 최대 5초
2. **의미 있는 선택**: 매 1~3분마다 전략적 판단 기회
3. **적절한 텐션**: 자동 70% + 능동 30%로 지루하지 않게
4. **명확한 성장**: 5억 → 1,000억까지 시각적으로 확인 가능

## 7. 메타 게임 루프 (N판 반복)

### 7.1 메타 루프 개요

**1판 루프**는 30년 플레이 → 등급 획득으로 끝나지만,  
**메타 루프**는 플레이어가 여러 판을 반복하며 성장하는 구조입니다.

```
1회차 플레이 (기본 시스템만)
    ↓
등급 확인 (D등급)
    ↓
새 시스템 해금 (리모델링)
    ↓
2회차 플레이 (리모델링 활용)
    ↓
등급 확인 (B등급)
    ↓
새 시스템 해금 (정책 개입)
    ↓
3회차 플레이 (전략 다양화)
    ↓
등급 확인 (A등급)
    ↓
모든 시스템 숙달
    ↓
N회차 플레이 (S등급 도전)
```

### 7.2 점진적 해금 시스템

플레이 회차에 따라 시스템을 점진적으로 해금하여 **학습 곡선을 완화**합니다.

#### 1회차: 기본 시스템 (진입 장벽 최소화)
- **사용 가능**: 매수/매도, 시세 차트, 기본 뉴스
- **목표**: 게임 흐름 이해, D~C등급 달성
- **학습 시간**: 5분 이내

#### 2~3회차: 건물 관리 (깊이감 추가)
- **해금**: 리모델링, 임대료 조정
- **해금 조건**: 1회차 완료 or C등급 달성
- **목표**: 건물 가치 최적화, B등급 달성

#### 4~5회차: 금융 시스템 (전략 다양화)
- **해금**: 대출 시스템 (LTV), 레버리지 활용
- **해금 조건**: B등급 달성 or 순자산 100억
- **목표**: 공격적 투자, A등급 달성

#### 6회차 이상: 고급 시스템 (자유도 극대화)
- **해금**: 정책 개입, 지역 확장, 랜드마크 매수
- **해금 조건**: A등급 달성 or 순자산 500억
- **목표**: S등급 달성, 업적 수집

### 7.3 재도전 동기 부여

#### 등급 시스템
- F~S 등급으로 명확한 목표 제시
- 각 등급별 해금 보상

#### 업적 시스템
- **특수 조건 달성**: 
  - 무차입 투자자 (대출 없이 100억)
  - 건물 황제 (건물 10채 보유)
  - 시장 지배자 (한 구 전체 점유율 50%)
  - 랜드마크 수집가 (코엑스, 남산타워 보유)

#### 난이도 선택
- **시작 지역**: 강남 (어려움) vs 외곽 (쉬움)
- **초기 건물**: 고가 (어려움) vs 저가 (쉬움)
- **시작 연도**: 2004년 (표준) vs 2008년 (금융위기, 어려움)

### 7.4 PLC 확보 전략

#### 짧은 플레이타임 (30~60분)
- 부담 없는 1회 플레이
- 언제든 다시 시작 가능

#### 다양한 플레이 스타일
- 안전한 투자 vs 공격적 레버리지
- 분산 투자 vs 집중 투자
- 매매 차익 vs 임대 수익

#### 시각적 성장 피드백
- 플레이 기록 저장 (최고 등급, 최고 자산)
- 통계 확인 (총 플레이 시간, 회차별 성과)
- 해금 현황 (시스템/업적 진행도)
