# 시세 변동 알고리즘 (Price Algorithm)

> **목적**: 건물 가격의 월별 변동 로직, 시장 추세, 랜덤성을 정의

---

## 📋 개요

이 문서는 다음을 정의합니다:

1. **적정 가치 vs 시장가** - 펀더멘털 기반 가치와 실제 거래가 분리
2. **기본 변동 메커니즘** - 월별 가격 업데이트 방식
3. **평균 회귀 메커니즘** - 저평가/고평가 보정
4. **변동 요소** - 추세, 랜덤성, 유형별 특성
5. **시장 추세 시스템** - Global Trend 관리
6. **이벤트 영향** - 뉴스 및 정책 효과
7. **밸런싱** - 30년간 성장 곡선

## 1. 적정 가치와 시장가 분리 (Fair Value System)

### 1.1 핵심 개념

게임의 모든 건물은 **두 가지 가격**을 가집니다:

| 가격 유형 | 설명 | 변동 특성 | 용도 |
|---------|------|----------|------|
| **적정 가치** (`fair_value`) | 펀더멘털 기반 "진짜 가치" | 천천히 안정적으로 변동 | AI 판단 기준 |
| **시장가** (`current_price`) | 실제 거래되는 시세 | 빠르고 불규칙하게 변동 | 매수/매도 가격 |

**설계 의도**:
- 플레이어가 **저평가된 건물을 발굴**하는 전략적 재미
- "싸게 사서 비싸게 판다"는 투자의 본질 구현
- 시장가는 단기 변동, 적정 가치로 회귀하는 흐름

### 1.2 적정 가치 (Fair Value) 계산

적정 가치는 **건물의 펀더멘털**로 결정됩니다:

```
적정 가치 = 기본 가격 × 유형 계수 × 등급 계수 × 입지 계수 × 시장 성장 계수
```

| 요소 | 설명 | 예시 |
|-----|------|------|
| **기본 가격** | 건물 유형별 베이스 값 | 주거 8억, 상업 10억, 오피스 25억 |
| **유형 계수** | 고정 (1.0) | - |
| **등급 계수** | C급(0.7), B급(1.0), A급(2.0) | - |
| **입지 계수** | 역세권(1.3), 공원(1.1), 일반(1.0) | - |
| **시장 성장 계수** | Market Index / 100 | 초기 1.0, 30년 후 약 6.0 |

**계산 예시**:
```
주거 C급 역세권 건물 (2004년 초기)
= 8억 × 1.0 × 0.7 × 1.3 × 1.0
= 7.28억 (적정 가치)

같은 건물 (2034년, Market Index = 600)
= 8억 × 1.0 × 0.7 × 1.3 × 6.0
= 43.68억 (적정 가치)
```

### 1.3 적정 가치 변동

적정 가치는 **시장 전체 성장**을 따라 **천천히 상승**합니다:

```
새 적정 가치 = 현재 적정 가치 × (1 + 적정 가치 월 변동률)
적정 가치 월 변동률 = Global Trend × 2% + 입지 보너스

# Global Trend가 +0.5일 때
월 변동률 = 0.5 × 2% + 0.5% (역세권) = 1.5%
```

**특징**:
- 랜덤 변동 **없음** (안정적)
- Global Trend 영향을 받지만 **작게** 반영 (2%)
- 입지 보너스는 계속 누적

### 1.4 시장가 (Current Price) 변동

시장가는 **빠르고 불규칙하게** 변동하지만, 장기적으로 적정 가치로 회귀합니다:

```
새 시장가 = 현재 시장가 × (1 + 시장가 월 변동률)
시장가 월 변동률 = 기본 변동 + 평균 회귀 압력
```

**기본 변동** (기존 로직):
```
기본 변동 = Global Trend × 3% + 랜덤(-2%~+2%) + 유형 보정
```

**평균 회귀 압력** (핵심 추가 메커니즘):
```
가격 갭 = (시장가 - 적정 가치) / 적정 가치
평균 회귀 압력 = 가격 갭 × (-0.2)

# 예시 1: 저평가 (시장가 7억, 적정 가치 10억)
가격 갭 = -30%
회귀 압력 = -30% × (-0.2) = +6% (상승 압력)

# 예시 2: 고평가 (시장가 13억, 적정 가치 10억)
가격 갭 = +30%
회귀 압력 = +30% × (-0.2) = -6% (하락 압력)

# 예시 3: 적정가 (시장가 10억, 적정 가치 10억)
가격 갭 = 0%
회귀 압력 = 0% (압력 없음)
```

**설계 의도**:
- 저평가 건물: 시간이 지나면 **올라갈 확률 높음** → 매수 기회
- 고평가 건물: 시간이 지나면 **내려갈 확률 높음** → 매도 타이밍
- 적정가 건물: 시장 추세 따라 움직임

### 1.5 매물 가격 설정 (NPC 매물)

NPC가 시장에 내놓는 매물은 **적정 가치 대비 랜덤 할인/할증**:

```
매물 가격 = 적정 가치 × (0.85 ~ 1.15)
```

| 할인율 | 확률 | 의미 |
|-------|------|------|
| 0.85 ~ 0.95 | 30% | **저렴한 매물** (기회) |
| 0.95 ~ 1.05 | 40% | 적정가 매물 |
| 1.05 ~ 1.15 | 30% | 비싼 매물 (피해야 함) |

**플레이어 전략**:
1. 매물 가격과 적정 가치 비교
2. 적정 가치보다 싸면 매수 (할인된 가격)
3. 시간이 지나면 시장가가 적정 가치로 회귀하며 상승
4. 적정 가치 근처 또는 그 이상일 때 매도

**UI 표시 예시**:
```
┌─────────────────────────────────┐
│  역삼 오피스텔 A동               │
│  주거 · C급 · 역세권             │
├─────────────────────────────────┤
│  💵 매물 가격: 6.8억             │
│  💎 적정 가치: 7.5억             │
│  📊 평가: 저평가 (-9.3%) ✅      │
│                                 │
│  👉 추천: 매수 기회!             │
│     시간이 지나면 상승 가능성    │
├─────────────────────────────────┤
│  [  매수하기  ]  [  취소  ]      │
└─────────────────────────────────┘
```

## 2. 기본 변동 메커니즘

### 1.1 월별 가격 업데이트

**매월 1일**, 모든 건물의 가격이 다음 공식으로 업데이트됩니다:

```
새 가격 = 현재 가격 × (1 + 월 변동률)
```

### 1.2 월 변동률 계산

```
월 변동률 = 기본 추세 + 랜덤 변동 + 유형 보정 + 입지 보정
```

각 요소는 다음과 같이 계산됩니다:

| 요소 | 설명 | 범위 | 비고 |
|-----|------|------|------|
| **기본 추세** | 시장 전체 방향성 | -3% ~ +3% | `Market.global_trend` |
| **랜덤 변동** | 예측 불가능한 등락 | -2% ~ +2% | 난수 생성 |
| **유형 보정** | 건물 유형별 특성 | -1% ~ +1% | 주거/상업/오피스 |
| **입지 보정** | 역세권 등 | -0.5% ~ +1% | 지하철역 근접 시 |

**예시**:
```
기본 추세 = +1.5% (상승장)
랜덤 변동 = -0.8%
유형 보정 = +0.3% (주거 안정)
입지 보정 = +0.5% (역세권)

월 변동률 = 1.5% - 0.8% + 0.3% + 0.5% = +1.5%
새 가격 = 10억 × 1.015 = 10.15억
```

### 1.3 변동 제한 (안전장치)

과도한 변동을 방지하기 위한 제한:

```
월 변동률 제한 = -5% ~ +5% (단일 월 최대 변동폭)
```

만약 계산된 변동률이 범위를 초과하면 제한값으로 조정됩니다.

## 2. 시장 추세 시스템 (Global Trend)

### 2.1 Global Trend 개념

`Market.global_trend`는 시장 전체의 방향성을 나타내는 값입니다:

| 값 | 의미 | 월 평균 변동 |
|----|------|-----------|
| `-1.0` | 대폭락 (금융위기) | -3% ~ -2% |
| `-0.5` | 하락장 | -1.5% ~ -0.5% |
| `0.0` | 횡보장 | -0.5% ~ +0.5% |
| `+0.5` | 상승장 | +0.5% ~ +1.5% |
| `+1.0` | 대호황 (버블) | +2% ~ +3% |

### 2.2 Global Trend 변동 (자연스러운 흐름)

시장 추세는 매월 **서서히 변화**합니다:

```
새 추세 = 현재 추세 + 추세 변화량
추세 변화량 = 랜덤(-0.1 ~ +0.1) + 이벤트 영향
```

**예시 시뮬레이션** (30년간):

| 연도 | Global Trend | 시장 상태 |
|-----|-------------|----------|
| 2004 | +0.3 | 완만한 상승 |
| 2005 | +0.6 | 상승장 |
| 2008 | -0.8 | 금융위기 (큰 하락) |
| 2010 | -0.2 | 회복 중 |
| 2015 | +0.4 | 안정적 상승 |
| 2020 | -0.3 | 팬데믹 충격 |
| 2025 | +0.5 | 재상승 |
| 2034 | +0.2 | 안정기 |

### 2.3 추세 범위 제한

```
Global Trend 범위 = -1.0 ~ +1.0 (고정)
```

이 범위를 벗어나면 자동으로 조정됩니다.

### 2.4 추세의 관성 (Momentum)

추세는 급격히 변하지 않고 **관성**을 가집니다:

- 상승장일 때: 계속 상승할 확률 70%, 하락 전환 확률 30%
- 하락장일 때: 계속 하락할 확률 60%, 상승 전환 확률 40%

이는 `추세 변화량`의 난수 가중치로 구현됩니다.

## 3. 건물 유형별 변동 특성

### 3.1 유형별 변동 계수

각 건물 유형은 시장 추세에 **다르게 반응**합니다:

| 건물 유형 | 변동성 | 상승장 반응 | 하락장 반응 | 특징 |
|---------|-------|----------|----------|------|
| **주거** | 낮음 | +0.8배 | -0.7배 | 안정적, 변동 완만 |
| **상업** | 중간 | +1.0배 | -1.0배 | 시장 평균 추종 |
| **오피스** | 높음 | +1.2배 | -1.3배 | 변동성 크고 위험 |

**계산 공식**:
```
유형 보정 = Global Trend × 유형 계수 × 0.3

# 예시 (상승장 +0.6)
주거: +0.6 × 0.8 × 0.3 = +0.144% (안정)
상업: +0.6 × 1.0 × 0.3 = +0.18% (평균)
오피스: +0.6 × 1.2 × 0.3 = +0.216% (고수익)

# 예시 (하락장 -0.6)
주거: -0.6 × 0.7 × 0.3 = -0.126% (방어적)
상업: -0.6 × 1.0 × 0.3 = -0.18% (평균)
오피스: -0.6 × 1.3 × 0.3 = -0.234% (큰 하락)
```

**설계 의도**: 주거는 안전자산, 오피스는 고위험 고수익

### 3.2 등급별 변동 차이 (Phase 2+)

MVP에서는 제외, 향후 추가 고려:
- C급: 변동성 +20% (저가 건물은 변동 심함)
- B급: 변동성 기본
- A급: 변동성 -10% (고가 건물은 안정적)

## 4. 입지별 변동 특성

### 4.1 역세권 보너스

**지하철역 200m 이내** 건물은 추가 상승 압력:

```
입지 보정 (역세권) = +0.3% ~ +0.7% (매월)
```

**누적 효과**: 30년간 약 +150% ~ +300% 추가 상승

### 4.2 공원/녹지 인접 보너스

**공원 인접** 건물:

```
입지 보정 (공원) = +0.1% ~ +0.3% (매월)
```

### 4.3 입지 보정 없음

일반 건물은 입지 보정 `0%`

## 5. 랜덤 변동 (Noise)

### 5.1 랜덤성의 역할

시장을 **예측 불가능하게** 만들어 게임성을 높입니다:

```
랜덤 변동 = 정규분포 난수 (-2% ~ +2%)
```

평균 0%, 표준편차 1%의 정규분포 사용

### 5.2 랜덤 변동 제한

```
극단값 제한 = -2% ~ +2%
```

희귀하게 ±2% 발생하여 예상 밖 기회/위험 제공

## 6. 이벤트 영향 (MVP 간소화)

### 6.1 이벤트 종류

MVP에서는 **최소한의 이벤트**만 구현:

| 이벤트 | 영향 | 지속 기간 | 발생 빈도 |
|-------|------|---------|----------|
| **호재 뉴스** | `Global Trend +0.3` | 3개월 | 1년에 1~2회 |
| **악재 뉴스** | `Global Trend -0.3` | 3개월 | 1년에 1~2회 |
| **금융위기** | `Global Trend -0.6` | 12개월 | 30년에 1~2회 |

**예시 호재**: "GTX 건설 확정", "금리 인하 발표"  
**예시 악재**: "부동산 규제 강화", "금리 인상"

### 6.2 이벤트 적용 방식

```
이벤트 발생 시:
1. Global Trend에 즉시 영향 (+0.3 또는 -0.3)
2. 지속 기간 동안 유지
3. 종료 후 서서히 원래 추세로 복귀
```

### 6.3 이벤트 발생 확률 (MVP)

- 매월 5% 확률로 호재/악재 발생
- 호재 50%, 악재 50%
- 금융위기는 스크립트 이벤트 (2008년 고정)

## 7. MVP 구현 시나리오

### 7.1 단순화된 로직

MVP에서는 복잡도를 낮추기 위해:

```
월 변동률 = Global Trend × 3% + 랜덤(-2% ~ +2%) + 유형 보정
```

- ✅ Global Trend (시장 추세)
- ✅ 랜덤 변동
- ✅ 유형별 특성
- ⚠️ 입지 보정은 **고정 보너스**로 간소화
- ❌ 등급별 차이 제외
- ❌ 개별 건물 히스토리 제외

### 7.2 월별 업데이트 프로세스

**매월 1일**:
1. Global Trend 업데이트 (`추세 변화량` 적용)
2. 이벤트 확인 (발생 시 추세 조정)
3. 모든 건물 순회:
   - 월 변동률 계산
   - 새 가격 = 현재 가격 × (1 + 월 변동률)
   - `Building.current_price` 업데이트
4. Market Index 업데이트 (추적용)

### 7.3 초기값 설정

| 항목 | 값 |
|-----|-----|
| `Global Trend` | `+0.2` (완만한 상승) |
| `Market Index` | `100` |
| 기준 연도 | 2004년 1월 |

## 9. 시장 지수 (Market Index)

### 9.1 개념

시장 전체의 평균 가격 변동을 추적하는 지수:

```
Market Index (초기) = 100
Market Index (n개월 후) = 100 × (1 + 누적 평균 변동률)
```

### 9.2 활용

- 플레이어 수익률 vs 시장 수익률 비교
- 차트에 시장 평균선 표시
- 등급 산정 시 참고 (시장 대비 성과)

**예시**:
```
30년 후 Market Index = 600
플레이어 순자산: 5억 → 800억 (1600% 상승)
시장 대비 성과: 1600% / 600% = 2.67배 우수
→ S등급 자격
```

## 12. 구현 참고사항

### 12.1 난수 생성 방식

**랜덤 변동**에는 두 가지 방식 사용:
- **균등 분포**: -2% ~ +2% 범위에서 동일 확률
- **정규 분포** (권장): 평균 0%, 표준편차 1%로 생성 후 ±2% 제한


### 12.2 Global Trend 업데이트 로직

**매월 실행**:
1. 작은 랜덤 변화 (-0.1 ~ +0.1) 생성
2. 이벤트 영향 추가 (발생 시)
3. 현재 추세에 변화량 더함
4. -1.0 ~ +1.0 범위로 제한

### 12.3 건물 가격 업데이트 로직

**매월 1일 실행, 3단계 프로세스**:

**1단계: Fair Value 업데이트** (안정적 성장)
- 변동률 = Global Trend × 2% + 입지 보너스
- 새 Fair Value = 현재 Fair Value × (1 + 변동률)
- 특징: 랜덤 요소 없음, 안정적 상승

**2단계: Current Price 변동률 계산** (변동성 높음)
- 기본 추세: Global Trend × 3%
- 랜덤 변동: 정규분포 난수 (-2% ~ +2%)
- 유형 보정: 기본 추세 × 유형 계수 × 0.3
- 입지 보정: 고정 보너스 값

**3단계: 평균 회귀 압력 적용** (Fair Value로 수렴)
- 가격 갭 = (Current Price - Fair Value) / Fair Value
- 회귀 압력 = 가격 갭 × (-0.2)
  - 저평가 시 (갭 음수): 양의 회귀 압력 → 상승 유도
  - 고평가 시 (갭 양수): 음의 회귀 압력 → 하락 유도
- 최종 월 변동률 = 기본 추세 + 랜덤 + 유형 보정 + 입지 보정 + 회귀 압력
- 변동률 제한: -5% ~ +5%
- 새 Current Price = 현재 Price × (1 + 월 변동률)

**핵심 메커니즘**:
- Fair Value는 펀더멘털에 따라 안정적으로 성장
- Current Price는 변동하지만 장기적으로 Fair Value로 회귀
- 저평가 건물은 상승 압력, 고평가 건물은 하락 압력
- 평균 회귀 강도 20%로 적당한 속도로 수렴

## 15. 핵심 공식 요약

### 기본 가격 변동
```
새 가격 = 현재 가격 × (1 + 월 변동률)
월 변동률 = Global Trend × 3% + 랜덤(-2%~+2%) + 유형 보정 + 입지 보정
제한: -5% ~ +5%
```

### Global Trend 업데이트
```
새 추세 = 현재 추세 + 랜덤(-0.1~+0.1) + 이벤트 영향
제한: -1.0 ~ +1.0
```

### 유형 보정
```
주거: Global Trend × 0.8 (상승) / 0.7 (하락)
상업: Global Trend × 1.0
오피스: Global Trend × 1.2 (상승) / 1.3 (하락)
```

### 입지 보정 (MVP 고정)
```
역세권: +0.5% / 월
공원 인접: +0.2% / 월
일반: 0%
```

## 부록: 현실 vs 게임

| 항목 | 현실 (서울 강남) | 게임 (밸런싱) |
|-----|---------------|------------|
| 연 평균 상승률 | 2% ~ 4% | **5% ~ 8%** (재미 상향) |
| 금융위기 하락폭 | -20% ~ -30% | -40% ~ -60% (드라마틱) |
| 회복 기간 | 3~5년 | 1~2년 (빠른 템포) |
| 변동성 | 낮음 (안정) | **중간~높음** (게임성) |

**설계 의도**: 현실보다 성장이 빠르고 변동성이 커서 **타이밍 포착의 재미**를 극대화
