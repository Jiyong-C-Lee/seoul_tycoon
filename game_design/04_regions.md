## 1. 지역 데이터 구조 (Region)

```python
class Region:
    name: str              # 지역명 ("강남구", "서초구" 등)
    base_trend: float      # 기본 시세 트렌드 (월별)
    environment_factors: List[str]  # 환경 요인 ("지하철", "한강" 등)
    unlocked: bool         # 해금 여부
```
