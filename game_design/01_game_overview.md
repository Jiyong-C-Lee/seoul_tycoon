## 게임 개요
- 장르: 실시간 시뮬레이션
- 테마: 부동산 매매
- 핵심 메커니즘: 지도 위에서 건물 사고팔기
- 목표: 시간 내 최대한 많은 자산을 모으기

---

## 1. 게임 상태 (Game States)

### 1.1 메인 메뉴 (Main Menu)
**목적**: 게임 시작 진입점

**화면 구성**:
- 게임 타이틀
- "게임 시작" 버튼
- (추후 추가 가능) 난이도 선택

**전환 조건**:
- "게임 시작" 클릭 → 플레이 중 상태로 전환

---

### 1.2 플레이 중 (Playing)
**목적**: 메인 게임 플레이

**상태 특징**:
- 실시간으로 시간이 흐름 (일시정지 가능)
- 플레이어 입력 처리 가능
- 모든 게임 시스템 활성화

**전환 조건**:
- 30년(360개월) 경과 → 게임 클리어 상태
- 현금 < -5억원 (빚) → 게임 오버 상태

---

### 1.3 게임 오버 (Game Over)
**목적**: 파산 실패 화면

**화면 구성**:
- "파산!" 메시지
- 플레이 기간
- 최종 자산 (마이너스)
- "처음으로" 버튼

**전환 조건**:
- "처음으로" 클릭 → 메인 메뉴 상태

---

### 1.4 게임 클리어 (Game Clear)
**목적**: 30년 생존 성공 화면

**화면 구성**:
- "성공!" 메시지
- 최종 자산 현황
  - 보유 현금
  - 부동산 총 가치
  - 총 자산
- 달성한 맵 레벨
- "처음으로" 버튼

**전환 조건**:
- "처음으로" 클릭 → 메인 메뉴 상태

---

## 2. 메인 루프 구조

### 2.1 시간 흐름 시스템

#### 시간 단위
- **기본 단위**: 1개월
- **실시간 환산**: 1개월 = 3초
- **총 게임 기간**: 360개월 (30년)
- **순수 플레이타임**: 1,080초 (18분)

#### 시간 속도 제어
```
일시정지: 0배속 (시간 멈춤)
기본속도: 1배속 (1개월 = 3초)
2배속: 1개월 = 1.5초
4배속: 1개월 = 0.75초
```

#### 월별 처리 이벤트
매월 초(1일)에 다음 이벤트 발생:
1. **정산 처리** → [03_economy_simulation.md](03_economy_simulation.md) 참조
2. **시세 업데이트** → [03_economy_simulation.md](03_economy_simulation.md) 참조
3. **이벤트 체크** → [06_events.md](06_events.md) 참조
4. **파산 체크** → [03_economy_simulation.md](03_economy_simulation.md) 참조

---

### 2.2 입력 처리 (Input Handling)

#### 마우스 입력
1. **맵 클릭**
   - 건물 선택/정보 표시
   - 매수/매도 UI 표시

2. **UI 버튼 클릭**
   - 일시정지/재생
   - 속도 변경 (1x, 2x, 4x)
   - 매수/매도 확정
   - 메뉴 선택

#### 키보드 입력 (옵션)
- `SPACE`: 일시정지/재생 토글
- `1`, `2`, `4`: 속도 변경
- `ESC`: 선택 취소

---

### 2.3 업데이트 로직 (Update Loop)

```
[매 프레임]
1. 시간 업데이트
   - 일시정지 상태가 아니면 경과 시간 누적
   - 3초(또는 배속 적용) 경과 시 → 1개월 증가

2. 입력 처리
   - 마우스 위치 업데이트
   - 클릭 이벤트 처리
   - 키보드 입력 처리

3. 게임 로직 업데이트
   - 새로운 월이 시작되었다면 월별 처리 실행
   - 이벤트 효과 적용
   - UI 상태 업데이트

4. 상태 전환 체크
   - 게임 오버 조건 확인
   - 게임 클리어 조건 확인
```

---

### 2.4 렌더링 (Rendering)

```
[매 프레임]
1. 배경 그리기
   - 맵 타일 렌더링

2. 건물 그리기
   - 각 건물 스프라이트 렌더링
   - 선택된 건물 하이라이트

3. UI 그리기
   - 상단 정보 패널 (시간, 자산)
   - 하단 컨트롤 패널 (일시정지, 속도)
   - 팝업 UI (건물 상세, 매수/매도)

4. 이벤트 알림 그리기
   - 뉴스/이벤트 팝업
```

## 3. 게임 흐름도 (Flow Chart)

```
[게임 시작]
    ↓
[메인 메뉴]
    ↓ (게임 시작 클릭)
[게임 초기화]
    - 플레이어 생성 (현금 5억)
    - 맵 생성 (강남구, 20x20)
    - 건물 배치
    ↓
[플레이 중] ←──────────┐
    │                  │ (일시정지 토글)
    │ [매 프레임]       │
    │ - 시간 업데이트   │
    │ - 입력 처리       │
    │ - 로직 업데이트   │
    │ - 렌더링          │
    │                  │
    │ [매월 초]         │
    │ - 정산            │
    │ - 시세 변동       │
    │ - 이벤트 체크     │
    │ - 파산 체크       │
    │                  │
    ├─→ (현금 < -5억) → [게임 오버] → [메인 메뉴]
    │                                      ↑
    └─→ (360개월 완주) → [게임 클리어] ────┘
```

## 4. 성능 고려사항

### 4.1 최적화 포인트
1. **타일 렌더링**: 화면에 보이는 타일만 렌더링
2. **건물 업데이트**: 매월 초에만 일괄 처리
3. **이벤트 체크**: 불필요한 반복 계산 방지

### 4.2 데이터 관리
- 건물 데이터는 게임 시작 시 로드하여 메모리에 유지
- 맵 레벨 확장 시 필요한 타일/건물만 추가 생성

---

## 5. 확장 가능성

### 5.1 추후 추가 가능 기능
- **저장/불러오기**: GameState를 JSON으로 직렬화
- **통계 화면**: 월별 수익, 지역별 투자 비율 그래프
- **도전 과제**: 특정 조건 달성 시 보상
- **멀티플레이어**: 동일 맵에서 경쟁

### 5.2 모듈화 구조
```
game/
├── core/           # 게임 루프, 상태 관리
├── data/           # 데이터 클래스 (Player, Building 등)
├── systems/        # 시스템 로직 (거래, 시세, 이벤트)
├── ui/             # UI 컴포넌트
└── utils/          # 유틸리티 함수
```
